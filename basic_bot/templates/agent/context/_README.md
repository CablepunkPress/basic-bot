# CONTEXT README

Add Markdown files to this folder to give your agent additional knowledge each turn. This is the place for material that doesn't belong in the agent's persona: reference notes about a project, a style guide, background on a topic, or anything else you want the agent to keep in mind.

The system wraps these files under a single CONTEXT heading, so you do not need to add a top-level heading yourself. If you use multiple files, a second-level heading in each helps the agent tell them apart. Files load in alphabetical order, so naming them with a number prefix like 01- and 02- gives you control over their sequence.

When the context is no longer needed, simply remove the files. Markdown files beginning with an underscore are ignored by the system.
